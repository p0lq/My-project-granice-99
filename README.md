# Граница-99

Изометрическая 3D-игра на выживание. Unity 6000.6.6f1, URP, Input System.

Юг Казахстана, 1999 год. После «Пыльного фронта» в посёлке Сарыкудук остались «Серые».
Игрок ищет ключ от люка бункера «Подземка», включает в бункере питание и забирает
из лаборатории антидот «ПФ-2».

## Управление

| Клавиша | Действие |
|---|---|
| WASD | идти |
| Shift | бег (громко) |
| C | красться (тихо) |
| ЛКМ | удар в сторону курсора |
| E | действие: дверь, ящик, колодец, рубильник, люк |
| F | фонарик (садятся батарейки, «Серые» видят свет) |
| Q | выпить воды (+30 здоровья) |
| Колесо мыши | приблизить или отдалить камеру |
| Esc | пауза |

## Сцены

- `MainMenu`: главное меню и титры.
- `Village`: посёлок Сарыкудук.
- `Bunker`: бункер «Подземка».
- `Test`: площадка для проверки моделей и анимаций, в сборку не входит.

Сцены собираются из примитивов командами меню «Граница-99» в редакторе. После пересборки
ручные правки в сцене пропадают.

## Модели

Персонажи кладутся в `Assets/Art/Models` как `SK_Player.fbx` и `SK_Grey.fbx`, неподвижные
объекты с префиксом `SM_`. Клипы в Blender называются `Idle`, `Walk`, `Run`, `Attack`, `Hit`,
`Death` (по желанию `CrouchIdle`, `CrouchWalk`). Импорт и Animator Controller настраиваются
автоматически. Исходники `.blend` лежат в `Art/Source`.

## Сборка

File → Build Profiles → Windows → Build. Сцены уже стоят в списке в нужном порядке.

Авторы и сторонние ассеты: `Assets/Resources/Credits.txt` (этот же текст показывается в титрах).
